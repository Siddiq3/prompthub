## INTERACTION FLOW

### User Lands on Page (T+0s)

```
Visual: Page loads
  ↓
  DopamineHeroSection renders with pulsing stats
  
Stats Animation Timeline:
  T+0.2s: Stats appear (opacity 0→1, scale 0.95→1)
  T+2s: Pulse animation triggers (scale 1→1.05)
  T+3s: Badges rotate to new trending item
  T+4s: Pulse animation repeats
```

### User Scrolls to Carousel (T+8s)

```
Visual: Carousel auto-advances
  ↓
  TrendingCarousel first card slides in
  
Carousel Timeline:
  T+0s: Featured card renders
  T+4s: Auto-advance to next card
  T+4s: Spring animation: slide in from right (damping: 25)
  T+6s: Image zoom animation begins
  T+8s: Auto-advance again
```

### User Scrolls to Card Grid (T+15s)

```
Visual: Grid appears with staggered entrance
  ↓
  Each DopaminePromptCard renders with delay
  
Card Entrance Timeline:
  Card 1: opacity 0→1, y 20→0, scale 0.95→1 (delay 0ms)
  Card 2: opacity 0→1, y 20→0, scale 0.95→1 (delay 50ms)
  Card 3: opacity 0→1, y 20→0, scale 0.95→1 (delay 100ms)
  Card 4: opacity 0→1, y 20→0, scale 0.95→1 (delay 150ms)
  
Result: Cascading entrance effect (feels premium)
```

### User Copies Prompt (T+30s)

```
Action: Click "Copy" button
  ↓ LAYER 1 (VISUAL FEEDBACK) - 0.2s
    Button color: blue → green
    Ripple effect: scale 0→2, opacity 1→0
    Particle burst: 12 emoji particles disperse
    
  ↓ LAYER 2 (HAPTIC FEEDBACK) - 0ms (simultaneous)
    navigator.vibrate([10, 20, 10, 20, 20])
    Phone vibrates in reward pattern
    
  ↓ LAYER 3 (AUDIO FEEDBACK) - 0.1s
    Web Audio API plays 800Hz sine wave
    Tone fades out exponentially
    
  ↓ LAYER 4 (CONFIRMATION) - 3s
    Toast: "✓ Prompt copied!"
    Icon: ✓ (spinning animation)
    Auto-dismiss: 3 seconds
    
RESULT: Complete reward cycle = dopamine spike ✨
```

### User Continues Scrolling (T+40s+)

```
After 9 cards (Card 9):
  ↓
  RecommendationCard appears
  "✨ You might love these too"
  "Explore similar prompts"
  
Psychology: Variable reward = continued engagement
```
